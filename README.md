# 캘린더 위젯

여러 캘린더(Google, Outlook/Microsoft 365, 네이버, iCloud, 기타 ICS·CalDAV)의 일정을 한 화면에 모아 보여주는 Windows 바탕화면 위젯입니다. 읽기 전용입니다.

## 실행

```
npm install
npm start
```

처음 실행하면 화면 오른쪽 위에 위젯이 뜨고 작업 표시줄 트레이에 아이콘이 생깁니다. 위젯의 ⚙ 버튼이나 트레이 메뉴의 "설정…"에서 캘린더를 추가하세요.

## 설치 파일 만들기

```
npm run dist
```

`dist\CalendarWidget-Setup-<버전>.exe`가 만들어집니다(x64, 사용자별 설치, 설치 경로 선택 가능, 바탕화면·시작 메뉴 바로 가기 생성). 코드 서명을 하지 않았으므로 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다("추가 정보" → "실행").

## 캘린더 연결 방법

| 서비스 | 방식 | 준비할 것 |
|---|---|---|
| Google | ICS | 캘린더 설정 → 캘린더 통합 → "iCal 형식의 비공개 주소" |
| Outlook / M365 | ICS | 설정 → 캘린더 → 공유 캘린더 → "캘린더 게시" → ICS 링크 |
| 네이버 | CalDAV | `https://caldav.calendar.naver.com/`, 네이버 아이디, 비밀번호(2단계 인증 시 애플리케이션 비밀번호) |
| iCloud | CalDAV | `https://caldav.icloud.com/`, Apple ID, 앱 암호 |

설정 화면의 "연결 테스트"로 저장하기 전에 접속과 일정 수를 확인할 수 있습니다.

## 기능

- **목록 보기**: 오늘부터 N일(기본 14일)의 일정을 날짜별로 표시
- **월간 보기**: 이번 달부터 2개월 뒤까지 달력으로 보고, 날짜를 누르면 그날 일정 표시 (헤더의 ▦ / ☰ 버튼으로 전환)
- **크게 보기**: 헤더의 ⤢ 버튼으로 위젯을 큰 창(기본 1000×720)으로 키우고 ⤡로 되돌림. 작은 크기와 큰 크기를 각각 기억함
  - 너비 520px 이상이면 달력 칸에 점 대신 일정 제목(시간 포함)을 표시하고, 칸에 안 들어가는 일정은 "+n개"로 표시
  - 너비 760px 이상이면 선택한 날의 일정 목록을 달력 오른쪽에 표시
- 캘린더마다 색으로 구분, 반복 일정·예외일·개별 수정본·종일·여러 날 일정 처리
- 여러 캘린더에 같은 일정(같은 UID·시작 시각)이 있으면 하나만 표시
- N분마다 자동 새로고침(기본 15분), 시작 N분 전 Windows 알림(기본 10분)
- 한 캘린더가 실패해도 직전 일정을 유지하고 위젯 하단에 오류 표시
- **창 배치**: 바탕화면에 고정(기본, 다른 창들 뒤에 머묾) / 일반 창 / 항상 위
- 투명도, 위치·크기 잠금, Windows 시작 시 실행(설치본)

## 데이터 저장 위치

`%APPDATA%\CalendarWidget\` (개발 실행과 설치본이 같은 폴더를 씁니다)

실제 설정을 건드리지 않고 시험하려면 환경 변수 `CALENDAR_WIDGET_DATA_DIR`에 다른 폴더를 지정해 실행하세요.

- `config.json`: 캘린더 목록과 설정. ICS 비공개 주소와 CalDAV 비밀번호는 Windows DPAPI(Electron `safeStorage`)로 암호화됩니다.
- `cache.json`: 마지막으로 가져온 일정. 시작할 때 네트워크 없이 바로 표시하는 데 씁니다.

## 구조

```
src/main.js            창·트레이·동기화·알림·IPC
src/preload.js         렌더러에 노출하는 API (contextIsolation + sandbox)
src/lib/events.js      ICS 파싱과 반복 일정 전개 (node-ical)
src/lib/sources.js     ICS 다운로드, CalDAV 조회 (tsdav)
src/lib/store.js       설정 파일, 비밀값 암호화
src/lib/desktop.js     바탕화면 고정 (koffi로 user32 호출)
src/lib/icon.js        트레이·설치 아이콘 그리기
src/renderer/          위젯·설정 화면
scripts/make-icon.js   build/icon.png 생성
test/                  node --test 단위 테스트
```

## 바탕화면 고정 동작 방식

위젯 창의 소유자를 바탕화면 창(Progman)으로 바꾸고 맨 아래로 보냅니다. 그래서 다른 창들 뒤에 머물고, 위젯을 클릭해도 위로 올라오지 않습니다. Win+D(바탕화면 보기)를 누르면 바탕화면 레이어가 위젯을 덮는데, 이때 바탕화면이 포그라운드가 되는 것을 감지해서 위젯이 가려졌으면 다시 위로 올립니다. Explorer가 재시작되면 위젯 창이 함께 사라지므로 2초 뒤 다시 만듭니다.

## 알려진 제한

- 일정 추가·수정은 지원하지 않습니다(읽기 전용).
- Win+D 뒤에 위젯을 다시 보이게 하는 동작은 실제 화면에서 충분히 검증하지 못했습니다. 위젯이 보이지 않으면 트레이 아이콘을 클릭하세요.
- 게시된 ICS 주소(특히 Outlook)는 서비스 쪽 갱신 주기 때문에 변경 사항이 늦게 반영될 수 있습니다. 즉시 반영이 필요하면 공식 API(OAuth) 연동이 필요합니다.
- 회사 Microsoft 365 계정은 관리자 정책으로 캘린더 게시가 막혀 있을 수 있습니다.
